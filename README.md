# Практическая работа №4: Основные SQL-операции на примере двух таблиц

## 🎯 Цель работы
Изучить базовые операции реляционной алгебры в SQL: выборку, проекцию, объединение (UNION), разность (EXCEPT), пересечение (INTERSECT), декартово произведение (CROSS JOIN) и соединение (JOIN).

## ⚙️ Выполненные шаги
1. Создана база данных `shop` и две таблицы: `products1` и `products2`.
2. В таблицы добавлены тестовые данные.
3. Выполнены запросы (WHERE, SELECT, UNION, EXCEPT, INTERSECT, CROSS JOIN, JOIN, LEFT JOIN).
4. Создан дамп базы данных `dump.sql`.
5. База удалена и восстановлена из дампа.
